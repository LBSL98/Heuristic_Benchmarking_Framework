# M4 graph construction metadata

This directory records metadata-only graph construction plans and specifications for real graph candidates.

These records may define graph model choices, coordinate normalization, node and edge interpretation, local-only output paths and fail-closed guards. They do not authorize or record actual graph construction, node/edge materialization, benchmark input generation, solver execution, CART training, result-map updates, monograph claims, or raw/extracted/derived artifact commits.

## Current records

- `tigerline_roads_2025_06037_los_angeles_county_graph_construction_metadata.yaml`: specifies the first deterministic segment-vertex graph construction policy for the 2025 TIGER/Line Los Angeles County roads candidate.
