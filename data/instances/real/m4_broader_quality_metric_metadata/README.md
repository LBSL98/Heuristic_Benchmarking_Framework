# M4 broader quality-metric metadata

This directory records reduced quality metrics extracted from already-generated real-graph partition files.

These records may include cut edges, internal edges, cut ratio, block counts and balance summaries. They do not execute solvers, run full campaigns, add datasets, run meta-heuristics, train CART, update result maps, write monograph claims, or commit raw graph inputs, benchmark inputs, partition files, raw solver outputs or intermediate metric artifacts.

## Current records

- `tigerline_roads_2025_06037_los_angeles_county_broader_quality_metrics_1236.yaml`: records reduced quality metrics for the ten preregistered TigerLine broader solver partitions.
