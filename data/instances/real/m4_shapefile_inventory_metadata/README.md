# M4 shapefile inventory metadata

This directory records metadata-only inventories of real-graph source archives.

Inventory records may verify source hashes, list archive members, record sidecar presence, and capture shapefile header/schema metadata. They do not authorize graph construction, node/edge inference, benchmark input generation, solver execution, CART training, result-map updates, monograph claims, or raw/extracted/derived artifact commits.
