# M4 benchmark input metadata

This directory records metadata-only evidence for benchmark input generation from real graph candidates.

These records may summarize input files generated under ignored local cache paths and may record hashes, sizes and format metadata for local-only benchmark input artifacts. They do not authorize solver execution, smoke/pilot/campaign execution, CART training, result-map updates, monograph claims, or raw/extracted/derived/input/output artifact commits.

## Current records

- `tigerline_roads_2025_06037_los_angeles_county_benchmark_input.yaml`: records metadata for a METIS/KMETIS/KaHIP-compatible input generated from the local-only TigerLine Los Angeles County roads graph.
