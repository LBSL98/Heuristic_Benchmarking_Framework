# M4 bounded solver execution metadata

This directory records reduced mechanical metadata for bounded single-dataset solver execution gates.

These records may summarize command return codes, timeout status, durations, runtime paths, binary checks, partition parse status, line counts, hashes and block counts. They do not authorize a full campaign, create multi-dataset command plans, run synthetic expansion, run additional real graphs, run meta-heuristics, train CART, update result maps, write monograph claims, or commit raw/extracted/derived/input/output artifacts.
