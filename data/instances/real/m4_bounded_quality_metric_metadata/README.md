# M4 bounded quality-metric metadata

This directory records reduced quality metrics extracted from bounded single-dataset solver partitions.

These records may include cut edge counts, block sizes, imbalance summaries, parse status, input hashes, partition hashes and extraction metadata. They do not execute solvers, authorize a full campaign, create multi-dataset command plans, run synthetic expansion, run additional real graphs, run meta-heuristics, train CART, update result maps, write monograph claims, or commit raw/extracted/derived/input/output artifacts.

## Current records

- `tigerline_roads_2025_06037_los_angeles_county_bounded_quality_metrics_1219.yaml`: records reduced quality metrics for the six already-existing TigerLine Los Angeles County roads 2025 bounded solver partitions.
