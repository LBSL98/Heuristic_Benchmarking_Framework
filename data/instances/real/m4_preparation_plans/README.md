# M4 preparation plans

This directory records metadata-only preparation plans for admissible real graph candidates.

A preparation plan does not itself download data, inspect raw files, construct graphs, generate benchmark inputs, execute solvers, train CART, update the result map, write monograph claims, or commit raw/derived graph artifacts. It defines the intended local-only procedure and the next gate required before any operational action.

## Current plans

- `tigerline_roads_2025_06037_los_angeles_county_preparation_plan.yaml`: defines the local-only preparation policy for the 2025 TIGER/Line Los Angeles County roads candidate and admits only a later download/hash metadata gate.
