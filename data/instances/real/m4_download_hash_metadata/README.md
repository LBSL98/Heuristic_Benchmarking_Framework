# M4 download/hash metadata

This directory records metadata-only download/hash manifests for admissible real graph source packages.

These manifests may record source URL, local ignored-cache path, file size, SHA-256 and download environment. They do not authorize or record shapefile inspection, graph construction, benchmark input generation, solver execution, CART training, result-map updates, monograph claims, or raw/derived graph commits.

## Current records

- `tigerline_roads_2025_06037_los_angeles_county_download_hash.yaml`: records the ignored-cache download and SHA-256 metadata for `tl_2025_06037_roads.zip`.
