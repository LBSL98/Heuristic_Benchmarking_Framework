# M4 license/admissibility snapshots

This directory records license and admissibility snapshots for real graph candidates.

A snapshot may identify official sources, terms, citation requirements, redistribution boundaries and next admissible gates. A snapshot does not itself authorize download, graph construction, benchmark input generation, execution, CART training, result-map updates, monograph claims, or raw/derived graph commits unless stated by a later gate.
