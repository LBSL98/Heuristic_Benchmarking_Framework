# M4 broader solver execution metadata

This directory records reduced metadata from bounded preregistered real-graph solver execution gates.

These records may include command identifiers, solver family, `k`, return code, timeout status, wall time, partition hashes, stdout/stderr hashes and parse status. They do not store raw graph inputs, benchmark inputs, partition files, raw solver outputs or intermediate metric artifacts. They do not extract or recompute cut/imbalance/quality metrics, authorize a full campaign, run meta-heuristics, train CART, update result maps or write monograph claims.

- `tigerline_roads_2025_06037_los_angeles_county_broader_solver_execution_1233.yaml`: records reduced execution metadata for the ten preregistered TigerLine Los Angeles County roads 2025 commands from issue #234.
