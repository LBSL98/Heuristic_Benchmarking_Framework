# M4 limited pilot retry metadata

This directory records reduced metadata for bounded TigerLine limited-pilot retries.

These records may summarize command return codes, runtime paths, binary checks, partition parse status and mechanical execution status. They do not authorize a full campaign, multi-dataset command plans, synthetic benchmark expansion, additional real-graph execution, meta-heuristic execution, performance or quality comparison claims, CART training, result-map updates, monograph claims, or raw/extracted/derived/input/output artifact commits.
