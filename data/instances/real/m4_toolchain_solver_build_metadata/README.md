# M4 toolchain and solver build metadata

This directory records metadata-only toolchain remediation and user-local solver build attempts for real-graph confirmatory candidates.

These records may summarize toolchain provisioning, package versions, user-local prefixes, source URLs, commits when available, build commands, binary paths, help/version probes, and checksums. They do not authorize TigerLine solver execution, pilot execution or re-execution, graph partition generation, campaign execution, multi-dataset command plans, meta-heuristic execution, performance or quality comparison claims, CART training, result-map updates, monograph claims, or raw/extracted/derived/input/output artifact commits.
